Math LIBBS — Station 2

Interactive installationRFIDUI designFront-endBackendOffline
Role
Entire project: UI design, front-end and backend
Format
16:9 landscape, 25 screens
Stack
HTML, CSS, JavaScript · Docker

Visitors place patient, medication and complementary-treatment cards on three RFID readers. The screen reacts in real time: it assembles the patient profile, says whether the combination is appropriate and explains why. The third reader simply records which complementary option the visitor picked, with no verdict.

The client gave me a key visual (KV), not finished screens. I designed every screen from it: the layout, the buttons, how each reader state is shown, and how the app explains a combination to the visitor.

It had to run offline on the show floor, so I built it in plain HTML, CSS and JavaScript with no libraries, to keep it fast. The backend runs in Docker, and one launcher file (.bat) starts everything, because the person running the stand could not be expected to type terminal commands.

Pfizer — clinical case quiz

Touch kioskVertical 9:16UI designFront-endBackendOffline
Role
Entire project: UI design, front-end and backend
Format
9:16 portrait, 23 screens
Stack
HTML, CSS, JavaScript · SQL · Docker

A touch quiz built around a clinical case for an event kiosk. Starting from a KV, I designed the screens and the flow, including how the buttons behave and the privacy policy step in the visitor registration.

It runs offline on site: plain HTML, CSS and JavaScript with no libraries, a lightweight SQL database for the registrations, Docker for the backend and the same one-click .bat launcher. The team reviews registrations in a protected area.

Since then I have built responsive email, campaign assets, WordPress sites and component libraries for agencies and large companies, and I now also design interface standards and user flows for a learning platform.
